## Streamlit Dashboard Execution

### Step 1: Clone Repository

```bash
git clone https://github.com/veerasuresh-hub/Regimeaware-RL-Portfolio-optimization.git
```

### Step 2: Navigate to Project Folder

```bash
cd Regimeaware-RL-Portfolio-optimization
```

### Step 3: Install Required Libraries

```bash
pip install -r requirements.txt
```

### Step 4: Launch Dashboard

```bash
streamlit run streamlit_dashboard.py
```

The dashboard will automatically open in the browser using:

```text
http://localhost:8501
```
